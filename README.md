# AtliQ Grands Hospitality Analysis

## 📌 Project Overview

This project was completed as part of the **Codebasics Resume Project Challenge-1 (Hospitality Domain)**.

The analysis focuses on **AtliQ Grands**, a luxury hotel chain operating across multiple cities in India. The objective of this project is to analyze key hospitality metrics and generate actionable business insights using Power BI.

The project simulates a real-world business scenario where stakeholders rely on data-driven insights to improve hotel performance and support strategic decision-making.

## 🚀 Solution Approach

- Data Cleaning and Transformation using Power Query
- Data Modeling
- DAX Measures Creation
- Interactive Dashboard Development
- Business Insight Generation
